# Thermal Calculator
Created this at my internship to calculate how much offset to CNC at with varying temperatures in the shop due to thermal expansion values. Calculator assumes isotropic material, linear thermal expansion, uniform temperature throughout the part. Also includes measurement instrument offset: what the instrument will read based on its own thermally expanded state. Vibe-coded UI elements and manually computed and coded calculations.
